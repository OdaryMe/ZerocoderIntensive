# Signal — AI Job Digest

Signal — это лёгкое адаптивное Flask-приложение для сбора и анализа вакансий в направлениях вайб-кодинга, промпт-инжиниринга и смежных AI-профессий.

Приоритеты проекта: **достоверность данных → работающая функциональность → оригинальный адаптивный дизайн → простота кода**. Приложение работает одной командой `python app.py`, без внешних клиентских фреймворков (только HTML5 + CSS3 + Vanilla JS).

## Возможности

- **Фильтрация и поиск.** Поиск по названию/компании/описанию, фильтры по направлениям, уровням, формату работы, стране, занятости, зарплате (с валютой), дате публикации, меткам «Новые», «В избранном».
- **Сортировка.** По дате обнаружения, дате публикации, зарплате (номинал), по релевантности собственным критериям.
- **Оценка релевантности.** Прозрачные правила (направление, ключевые навыки, заголовок, зарплата), критерии можно настроить в панели «Мои критерии».
- **AI-дайджест.** Локальная аналитика без нейросети: количество вакансий, распределение по направлениям/навыкам, зарплатные диапазоны, «Обнаружены недавно». Блок AI-резюме отображается честно — не активируется без настроек `AI_API_KEY`.
- **Дедупликация и источники.** Архитектура подключения реальных источников (RSS/API) с дедупликацией; текущий режим работы отображается в статусе.
- **Демо-режим.** Работает «из коробки» с явными тестовыми данными. Демо-записи помечены тегом `ДЕМО`, у них нет ссылок — в интерфейсе показывается «Ссылки нет».
- **Экспорт.** Выгрузка отфильтрованного списка в CSV (с BOM для корректного открытия в Excel).
- **UX.** Тёмный оригинальный дизайн, адаптивная вёрстка (брейкпоинты 1140/1020/980/860/760/640/560/420 px), мобильное меню, тосты, пустое состояние, drawer-детали вакансии.

## Требования

- Python 3.10+
- Flask, python-dotenv

Установить зависимости: `pip install -r requirements.txt`

## Установка

1. Клонируйте репозиторий (или скопируйте папку `signal-ai-job-digest`).
2. Перейдите в каталог проекта:
   ```bash
   cd signal-ai-job-digest
   ```
3. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows (PowerShell/cmd)
   # или source .venv/bin/activate (Linux/macOS)
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Скопируйте пример конфигурации:
   ```bash
   copy .env.example .env  # Windows
   # или cp .env.example .env
   ```

## Конфигурация (.env)

Доступные переменные (все опциональны):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SIGNAL_FEEDS` | _(пусто)_ | Список RSS/Atom-URL через запятую или перенос строки (подключение реальных источников). Если не задан — приложение работает в демо-режиме. |
| `SIGNAL_UPDATE_INTERVAL_HOURS` | `6` | Интервал автообновления (не используется в текущей однопроцессной версии, зарезервирован). |
| `SIGNAL_MAX_PER_FEED` | `50` | Максимум вакансий с одной ленты при обновлении. |
| `SIGNAL_DEMO_SEED` | `default` | Сид для генерации демо-данных. |
| `AI_API_KEY` | _(пусто)_ | Ключ для генерации AI-резюме в дайджесте. Если пуст — AI-резюме не формируется (аналитика остаётся локальной и честной). |
| `AI_API_URL` | _(пусто)_ | URL провайдера (например, OpenRouter/LM Studio). |
| `AI_MODEL` | _(пусто)_ | Модель нейросети. |
| `FLASK_ENV` | _(пусто)_ | Режим Flask (не обязателен). |

> Важно: приложение **не выдаёт фильтрацию за ИИ**. Локальная аналитика (дайджест) рассчитывается по правилам, без обращения к нейросети. Нейросеть используется только для опционального текстового AI-резюме при наличии `AI_API_KEY` и `AI_API_URL`.

## Запуск

```bash
python app.py
```

Приложение запустится на `http://127.0.0.1:5000`. Открыть в браузере: [http://127.0.0.1:5000](http://127.0.0.1:5000).

Для Windows с изолированным Python (например, с режимом `._pth` без автоматического добавления текущего каталога в `sys.path`) `app.py` содержит обязательный шим `sys.path.insert(0, dirname(abspath(__file__)))`. Это гарантирует, что модули проекта импортируются корректно при запуске `python app.py` из каталога проекта.

## Режимы работы

- **Демо (`mode: demo`)** — включается, если `SIGNAL_FEEDS` не указан. Используются `data/demo_jobs.json`. Даты демо-записей хранятся в виде «сколько дней назад» и **перегенерируются при каждом запуске/обновлении** (демо-данные не являются статичной историей, а обновляются относительно текущей даты).
- **Демо + RSS (`mode: demo+rss`)** — если `SIGNAL_FEEDS` заданы. Сначала загружаются демо-данные (для наглядности), затем проверяются RSS-ленты. Новые вакансии добавляются с дедупликацией по ключу (`title+company+url`).

Статус последнего обновления и результаты по источникам отображаются в шапке/мобильном меню и доступны по `GET /api/status`.

## API (основные маршруты)

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/` | Главная страница (SSR: hero, фильтры, дайджест-каркас, источники) |
| `GET` | `/api/jobs` | JSON-список вакансий с фильтрацией/сортировкой/пагинацией |
| `GET` | `/api/jobs/<id>` | Детали одной вакансии |
| `POST` | `/api/update` | Принудительное обновление данных (проверка источников) |
| `GET` | `/api/status` | Статус последнего обновления |
| `GET` | `/api/digest?days=N` | Локальный дайджест за период N (1,3,7,14,30) |
| `POST` | `/api/ai-summary` | Опциональное AI-резюме (только при наличии ключей) |
| `GET` | `/api/export.csv` | Экспорт текущего набора в CSV |
| `GET` | `*` | 404 страница |

## Подключение реальных источников

1. Укажите ссылки в `.env`:
   ```env
   SIGNAL_FEEDS=https://example.com/feed.xml, https://example.org/rss
   ```
   Можно через запятую или построчно.
2. Настройте парсинг при необходимости в `sources.py` (адаптация под формат конкретной ленты). Архитектура уже подготовлена (RSS/Atom, дедупликация, обработка ошибок).
3. Перезапустите приложение. Режим станет `demo+rss`.

> Обратите внимание: в текущей версии проект демонстрационный — реальные источники не подключены по умолчанию. README не заявляет об их гарантированной работе без адаптации форматов лент.

## Расширение проекта

- **Новые направления.** Добавьте правила в `directions.py` (ключевые слова/синонимы). Фильтры и дайджест автоматически учтут изменения.
- **Новые источники.** Расширьте `sources.py` (парсеры, нормализация полей). Старайтесь не выдумывать отсутствующие данные — сохраняйте честные значения (`None` → «Не указана», отсутствие ссылки → «Ссылки нет»).
- **Правила релевантности.** Измените веса в `relevance.py` — расчёт прозрачен и отображается в интерфейсе.

## Известные ограничения

- Сервер разработки Flask (`python app.py`) предназначен для локальной демонстрации, не используется в production.
- Демо-даты перегенерируются при старте/обновлении — это осознанное поведение для демо-режима.
- При изолированном Python (safe_path/`._pth`) необходим `sys.path`-шим в `app.py` — он уже присутствует.
- Кодировка вывода в PowerShell (cp1251) не влияет на работу приложения и корректность данных.
